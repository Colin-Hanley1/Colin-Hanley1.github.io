On the deployment of applied ML models in difficult, real-world domains†

Colin J. Hanley University of Alabama · Dept. of Mathematics & Data Science
Abstract —

We present a portfolio of four deployed predictive systems operating in healthcare, epidemiology, conservation, and sports analytics. Contributions include a 24-state absorbing Markov chain for first-inning baseball run scoring, a Transformer-based groundwater model using Multiresolution Hash Encoding, an agent-based epidemic simulator, and a thermal-UAV object detector. Code is public; plots are interactive; opinions are strong but well-regularized.

TRY IT Click Run simulation to draw 10,000 innings. The histogram fills in real time.
RESULT The empirical P(NRFI) should converge near the analytic fixed point from the fundamental matrix.

Given an absorbing Markov chain over 24 base-out states, we can compute exact NRFI probabilities via fundamental matrix inversion (I − Q)⁻¹. The Monte Carlo estimator below is a sanity check — it should agree with the analytic solution to within the standard error.

def simulate_inning(lineup, P): # returns 1 if inning scored, else 0 runs = 0 state = (0, 0) # (bases, outs) while state[1] < 3: outcome = np.random.choice(OUTCOMES, p=P[batter]) state, runs = transition(state, outcome, runs) return 1 if runs > 0 else 0 draws = [simulate_inning(lineup, P) for _ in range(10_000)] p_nrfi = 1 - np.mean(draws)
